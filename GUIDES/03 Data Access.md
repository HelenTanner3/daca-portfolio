# 03 Data Access

See jaotis koondab juhendid, mis käsitlevad andmeallikatele ligipääsu, ühenduste seadistamist, andmete laadimist analüüsikeskkonda ning SQL-põhist andmetöötlust.

## Connections

- [Supabase → Python → pandas](connections/supabase_python_pandas_connection.md)  
  `.env`, Supabase'i Pythoni klient, andmete lehekülgede kaupa laadimine, pandas DataFrame'id, RLS, `left` merge'id ja kontrollid.

## SQL

SQL-i alamkausta kuuluvad juhendid, mis käsitlevad:

- `SELECT`, `WHERE`, `ORDER BY`;
- andmete puhastamist;
- `JOIN`-e;
- `GROUP BY`, agregatsiooni ja `HAVING`-ut;
- andmekvaliteedi kontrolle;
- Supabase SQL Editori kasutamist.
