# Täiendavad analüüsid

See kaust sisaldab kahte Nädal 8 ametlikku Roll D tööd toetavat, kuid eri ajal tehtud lisaprotsessi.

## Sisu

### [A–B–C integratsioonitest](abc-integration-test/)

Valmis **enne lõpliku grupipipeline'i kinnitamist**. Eesmärk oli kontrollida Rollide A, B ja C omavahelist sobivust, andmekvaliteeti ja vahetulemusi enne Roll D lõplikku integratsiooni.

### [RFM automatiseerimine](rfm-automation/)

Valmis **pärast grupitöö lõppu ja esitlusel saadud tagasisidet**. Nädal 7 RFM-analüüs ühendati Nädal 8 API-pipeline'iga, et muuta see korduvkäivitatavaks.

Mõlema töö detailne taust, kontrollid ja seos Nädal 8 õppimisprotsessiga on kirjeldatud [`../analysis.md`](../analysis.md) failis.
