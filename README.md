See portfoolio dokumenteerib minu arengut DACA andmeanalüütiku programmis ning praktilisi töid UrbanStyle'i õppeandmestikuga.

## 🎯 Portfoolio eesmärk

Minu taust on finantsjuhtimises ja controlling'us. Koolituse jooksul olen laiendanud oma oskusi SQL-i, Power BI, Pythoni, API-de ja andmetöötluse automatiseerimise suunas.

Fookus on andmete muutmisel usaldusväärseks juhtimisinfoks: lisaks analüüsile ja visualiseerimisele pööran tähelepanu andmekvaliteedile, kontrollväärtustele ning tulemuste ärilisele tõlgendamisele.

## 📁 Repo ülesehitus

Portfoolio on jaotatud tehnoloogia- ja tööetappide kaupa. Iga teemakausta sees säilib nädalapõhine õpiteekond.

```text
daca-portfolio/
├── 00-setup/                   # Nädal 0
├── 01-sql/                     # Nädalad 1–4
├── 02-power-bi/                # Nädalad 5–6
├── 03-python/                  # Nädalad 7–8
├── 04-career/                  # Nädal 9
└── 05-portfolio-presentation/  # Nädal 10
```

Nädalakaustade dokumentatsioon järgib võimaluse korral ühtset loogikat:

```text
week-x/
├── README.md
├── analysis.md             # analüüsinädalatel
├── põhiartefakt            # .sql / .ipynb / .py / .pbix / .pptx / .pdf
├── screenshots/            # .png / .jpg / .html
├── additional-analysis/    # vajaduse korral
└── supporting/             # vajaduse korral
```

Nädal 0 on seadistuste nädal ja Nädal 10 portfoolio esitlus, mistõttu nende dokumentatsioon võib tavapärasest analüüsinädala struktuurist erineda.

`README.md` annab projektist lühikese ülevaate, `analysis.md` sisaldab analüüsinädalatel detailsemat analüüsi, kontrolle ja järeldusi ning põhiartefakt näitab tehtud tehnilist tööd. Kuvatõmmised ja täiendavad materjalid lisatakse siis, kui need toetavad projekti mõistmist või tulemuste tõendamist.

## 🔍 Tööviis ja kvaliteedikontroll

Portfooliotöödes ei käsitle ma edukat päringut, visualiseeringut või koodikäivitust iseenesest tõendina, et tulemus on õige. Kontrollin vastavalt ülesandele näiteks:

- ridade arvu ja võtmete unikaalsust;
- NULL-väärtusi ja duplikaate;
- JOIN-ide ja puhastamise mõju;
- kuupäevavahemikke ja analüüsiperioodi;
- summasid, KPI-sid ja muid referentsväärtusi.

Detailsemad tööetapid, kontrollid, piirangud ja järeldused on dokumenteeritud nädalate `analysis.md` failides.
